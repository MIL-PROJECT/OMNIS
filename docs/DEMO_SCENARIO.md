# OMNIS 15분 평가 시연 시나리오

## 사전 준비

1. 관리자 `demo_admin / Demo!2026`로 로그인한다.
2. **통제·일일마감 → 평가 시나리오 준비**를 누른다. 기존 사용자 데이터는 삭제하지 않는다.
3. 상단의 `오프라인 · 가상 시연 데이터` 표시를 설명한다.

## 0:00~1:00 문제와 개선 목표

- 화면: 로그인 후 통합상황판.
- 설명: “게시판·유선 접수, 정비반 배정, 작업계획, 일일대조가 분리되면 미조치와 기록 불일치가 생깁니다. OMNIS는 이 과정을 로컬 PC의 한 workflow와 감사 이력으로 연결합니다.”

## 1:00~3:00 통합상황판

- 클릭: **통합상황판**의 긴급 장애 카드, 운영 체계 행, **통제 화면** band.
- 확인: 체계 상태, 긴급 미종결, 금일 접수·완료, 상황경보, SLA 초과, 계획/비계획, 근무인원, 갱신시각.
- 설명: KPI 클릭 후 실제 상세 데이터와 이력으로 drill down된다.

## 3:00~8:00 고장 접수부터 종결

### 일반 고장

1. **고장관리 → 신규 고장 접수**.
2. 제목 `가상 지휘통신 회선 간헐 중단`, 접수수단 `유선`, 서비스 영향 `가상 지휘망 일부 지연`, 중요도 `긴급`.
3. 저장 후 상세에서 `분류`.
4. 상세의 **첨부자료 → 파일 선택**에서 가상 로그·점검표를 등록하고 분류·크기·등록자·시각을 확인한다.
5. **AI 분류** → 근거·신뢰도·추천 정비반 확인 → **검토 후 반영**.
6. 정비반과 담당자 선택 → **정비반 배정**.
7. `원격조치` → 처리 메모 `가상 회선 재설정 시도`.
8. `현장출동` → 처리 메모 `원격 조치 미해결, 가상 현장 점검 전환`.
9. `조치완료` → 원인, 조치결과, 현장 방식, 재발위험, 후속점검일 입력.
10. `검증` → `종결`, 사용자 확인 체크.
- 예상: 타임라인에 모든 상태와 수행시각이 남고 잘못된 순서의 버튼은 제공되지 않는다.

### 긴급 선조치

- 신규 접수에서 `작전 긴급요청`, `긴급 선조치 후 사후 접수`를 선택하고 선조치 사유·실제 시작시각을 입력한다.
- 예상: 상세에 빨간 선조치 기록이 표시되고 필수값이 없으면 저장되지 않는다.

## 8:00~11:00 AI 활용

- 화면: 고장 상세의 AI 검토 패널과 SLA 위험 패널, **AI 지원**의 유사 사례.
- 설명: AI는 장애유형·긴급도·정비반·초기조치·예상시간·확인질문을 구조화해 제안한다. 사람이 수정·승인해야 반영된다.
- 오프라인 장애 시연: 시스템관리에서 Ollama의 미실행 endpoint를 선택하고 분석한다. timeout/접속 실패 후 Local Rule로 복구되고 fallback 이력이 기록된다.
- 외부 AI 시연(선택): 실제 기밀·개인정보가 없는 가상 문구만 사용한다. 시스템관리에서 OpenAI 또는 Anthropic Key를 저장하고 동의·활성화 후 연결 시험을 누른다. AI 지원에서 실제 Provider/model/latency/외부 전송 표시를 확인한 뒤 시연 후 LOCAL로 되돌리고 Key를 삭제한다. 실제 API 비용이 발생할 수 있다.

## 11:00~13:00 일일 마감·인수인계

1. **통제·일일마감 → 08:30·16:00 작업판**.
2. 계획, 비계획, 완료, 이월, 미완료 사유 입력.
3. **정합성·마감**에서 결과 누락과 상태 불일치 확인.
4. ADMIN으로 일일 마감. 이상이 있으면 예외 승인 확인창을 설명한다.
5. **근무 인수인계** → 초안 생성 → 문구 수정 → 확정.

## 13:00~14:00 차별성과 확장성

- SLA 위험, 선조치 사후기록, 원격→현장 전환, 정합성 snapshot, AI 실행 추적, 역할별 Main 권한을 설명한다.
- 외부 AI는 선택 기능이며 기본 LOCAL 시연에는 네트워크가 필요 없다. API Key는 safeStorage로 보호되고 renderer에는 masked 상태만 표시됨을 설명한다.

## 14:00~15:00 증빙과 초기화

- **시스템관리 → 감사 로그**에서 주요 mutation을 확인한다.
- **통제·일일마감 → 시연 초기화**는 OMNIS가 생성한 평가 시나리오만 삭제한다.
- 전체 데이터 초기화는 별도 2단계 확인과 백업을 거친다.

## 실패 대비

- Ollama 미실행: Local Rule 결과로 계속한다.
- 시나리오 중 데이터 오류: 평가 시나리오 초기화 후 다시 준비한다.
- 창 크기: 1366×768에서는 브라우저 배율을 바꾸지 않고 좌측 메뉴와 DataGrid pagination을 사용한다.
