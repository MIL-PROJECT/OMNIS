# Demo Scenario

1. `demo_admin`으로 로그인하여 통합상황판의 가상 데이터를 확인합니다.
2. 고장관리에서 신규 고장을 등록하고 접수번호가 생성되는지 확인합니다.
3. 고장을 분류·배정·진행·완료로 변경하고 이력을 확인합니다.
4. 정비관리에서 작업을 등록하고 캘린더에서 예정일을 확인합니다.
5. AI 지원에서 가상 장애 문장을 분석하고 추천만 제시되는지 확인합니다.
6. 보고서에서 일일 현황과 CSV를 확인합니다.
7. 앱을 종료하고 다시 열어 등록한 고장과 정비가 남아 있는지 확인합니다.
8. 시스템관리에서 백업을 실행하고 파일을 확인합니다.
