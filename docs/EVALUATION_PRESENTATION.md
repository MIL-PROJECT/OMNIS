## 범위와 검증

실제 설치 앱을 새 격리 프로필로 촬영했다. 일부 상태와 계획 숫자는 검증된 Main 업무 API로 준비한 합성 시연 자료다. 화면은 관심 영역을 확대하고 읽기 시간을 위해 끝 프레임을 유지했다. 생성형 모델의 실제 정확도·유료 API·타체계 양방향 실연동·다중 PC 운용 성능을 입증한 영상으로 표현하지 않는다.

전체 미디어 디코딩, 153개 자막과 원문 일치 등 제작 검사 82개를 통과했고, 30개 장면과 12개 세부 전환을 시각 검토했다. 기존 제품 시험 근거와 영상 제작 검사를 구분했다. 촬영 중 재현한 체계 미지정 AI 입력 계약 결함은 대조표·질의응답·품질검증 문서에 공개했다. 이번 자료 보존에서 제품 코드를 변경하지 않았다.
