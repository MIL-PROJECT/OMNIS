# OMNIS 운용개념 기술서

최상위의 제출본.hwp, 제출본.docx, 제출본.pdf를 사용하십시오. 모두 동일한 내용의 18쪽 문서입니다. HWP와 DOCX의 본문·표는 실제 편집 가능한 요소입니다. PDF는 최종 HWP에서 내보냈습니다.

- evidence/검증결과.md: 형식·내용·렌더·시험 결과와 한계
- evidence/양식_대응표.csv: 원문 7~8쪽과 문서의 항목 대응
- evidence/요구사항_구현근거표.csv: 요구사항별 현재 상태·소스·시험
- evidence/평가항목_증빙표.csv: 원문 배점 100점의 근거 대응
- evidence/작성자_확인사항.md: 인적사항·AI 기여율·보안·부분 충족 항목
- evidence/manifest.json: 최종 파일 크기·SHA-256
- evidence/figures/: 개념도 PNG와 편집 가능한 SVG, 실제 소스 발췌 이미지
- evidence/screenshots/: 가상 프로필의 최신 앱 실제 캡처
- evidence/rendered/: Word와 한글 PDF 전 페이지 렌더·비교(검증용)
- source/content.json 및 build_document.py: 편집 원본 및 문서 생성 코드
- source/export_hwp_r2.ps1, verify_word.ps1 등: 실제 변환·재열기 경로. 한글의 확인 창은 해당 생성 파일에 대해 접근 허용하며 보안 설정을 우회하지 않습니다.

source/의 probe·r2 파일은 변환 검증용 중간 산출물입니다. 제출에는 최상위 세 파일을 사용하십시오.

실제 작성자 인적사항은 비워 두었습니다. AI 지원 개발 기여율은 근거가 부족하여 산정 보류로 명시했습니다. 실제 API live 성공이나 군 실운용·공식 보안 승인을 주장하지 않습니다.
