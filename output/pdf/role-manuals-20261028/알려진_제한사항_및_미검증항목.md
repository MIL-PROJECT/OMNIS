## L01 다른 사용자의 고장 정보가 요약·유사 검색·CSV에 노출
실행 재현 P01·P02

일반 사용자는 본인 고장관리 화면을 기준으로 업무를 처리합니다. 다른 사람의 내용이 보여도 공유·활용하지 말고 관리자에게 알립니다.

## L02 일일 PDF와 화면의 한국 날짜 집계 차이
실행 재현 P03

자정~08:59 접수 건은 PDF에서 누락되거나 전날에 포함될 수 있습니다. 화면·번호·시각을 대조하고 차이를 보고합니다.

## L03 마감 후 작업판 수정이 완전히 차단되지 않음
실행 재현 P04

마감 후 숫자를 바꾸지 않습니다. 잘못된 마감·수치는 관리자와 개발 담당자에게 정정 요청합니다.

## L04 수정 폼의 대상 체계·발생 시각 저장 누락
실행 재현 P05

신규 등록 시 정확히 입력합니다. 수정창에서 값을 바꿨다는 사실만으로 정정 완료라고 판단하지 않습니다.

## L05 연계 정비가 있는 평가 시나리오 초기화 오류
실행 재현 P06

오류 시 중단합니다. 전체 초기화나 연계 자료 강제 삭제로 우회하지 않습니다.

## L06 저장한 인수인계를 다시 여는 화면 없음
현재 코드 확인

확정 내용을 승인된 별도 인계 기록에 보관합니다. DB에 저장되는 것과 앱에서 재조회 가능한 것은 다릅니다.

## L07 조회전용 화면에도 금지된 버튼 노출
UI14 실패 관찰 및 UI17 재확인

AI 분류와 인수인계 저장·확정은 금지입니다. 버튼이 보인다고 실행 권한이 있는 것은 아닙니다.

## L08 AI 리뷰의 추천값 직접 편집·되돌리기 없음
현재 코드 확인

맞지 않는 추천은 반영하지 않습니다. 이미 반영했으면 권한 있는 역할이 일반 수정·배정 절차로 확인합니다.

## L09 계정 역할 변경·비밀번호 찾기·복원 UI 없음
현재 코드 확인

계정 승인 후 권한 정정이나 비밀번호 문제, 복원 필요는 담당 개발자에게 요청합니다.

## L10 다중 PC 실시간 공유·외부체계 자동 연동 없음
현재 코드 확인

동일 PC의 계정 교대 흐름을 기준으로 사용합니다. 다른 PC에서 자동으로 업무를 인수할 수 있다고 가정하지 않습니다.

## L11 실제 Ollama·설치·macOS·장비 조작 미검증
이번 검증 범위 밖

Local Rule와 Windows 소스 실행을 검증했습니다. 실제 설치본 배포·장비 조작·외부 모델 품질을 보증하지 않습니다.

## L12 알림·로그·운용률의 의미 제한
현재 코드 확인

알림 읽음은 개인별 완료가 아니며 감사 로그는 모든 로그인 이력을 담지 않습니다. 운용률은 자동 장비 측정값이 아닙니다.
