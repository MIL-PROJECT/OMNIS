접수번호

접수 시 설정되는 처리 기준 기한. 실제 계약 준수나 복구 성공을 자동 보장하는 지표는 아닙니다.
조치완료 / 검증 / 종결
조치 기록 완료, 결과 검토, 요청자 확인 후 종료의 서로 다른 단계입니다.
계획 / 비계획
사전 계획에 포함된 작업인지 추가 발생 작업인지 구분합니다.

작업판에서는 완료 ÷ (계획+비계획)의 반올림 값이며 개별 정비 진행률과 다릅니다.

다음 근무·날짜에 이어서 처리할 건수. 입력만으로 다음날 작업이 자동 생성되는 것은 아닙니다.
정합성
기록 사이의 일치 여부. 시스템의 검사 범위 내 결과이며 전체 업무의 완전성 인증은 아닙니다.
정비반 / 개인 담당자
팀의 업무 책임과 개인의 실제 배정은 별도입니다. 권한 판단에도 서로 다른 조건이 적용됩니다.
Local Rule
로컬 규칙으로 분류·추천하는 제공자. 외부 대형 모델을 호출했다는 뜻이 아닙니다.
Fallback
설정한 제공자가 실패했을 때 대체 처리하는 동작. 화면의 대체 규칙 표시를 확인합니다.
신뢰도
추천 결과의 표시 수치. 검증된 정답 확률이나 안전 인증으로 해석하지 않습니다.
백업 / 내보내기
백업은 DB·관련 첨부 보관, 내보내기는 보고용 CSV/PDF 생성입니다.
마감
선택 날짜의 요약을 확정하는 관리 작업. 고장과 정비 자체를 모두 종결하는 기능은 아닙니다.
확인
지시 읽음, 경보 인지, 사용자 복구 확인 등 화면에 따라 의미가 다릅니다.
