# 평가 발표의 핵심 논지

OMNIS는 로컬 정보통신 운용·정비 업무에 **기록 연결, 추론 장애 대응, 사람의 반영 책임**을 함께 적용한 시스템이다. 평가 대상은 이 구성의 운용 적합성과 검증 가능한 경계다. 새로운 AI 알고리즘·세계 최초·상용 제품 대비 우위를 입증한 연구로 제시하지 않는다.

대상은 평가관과 개발자다. 기능 소개는 1분, 현재 아키텍처 3분, 세 가지 설계 차별성 3분에 배정한다. 나머지는 문제 정의, 확장 조건, 연동 방안, 시험 근거와 현장 실증 계획이다. 영상은 한국어 합성 음성(macOS Yuna), 30개 장면, 실제 설치 앱의 격리 촬영을 사용한다.

| 평가할 차별성 | 현행 구현 근거 | 운용 가치 가설 | 아직 입증하지 않은 부분 |
|---|---|---|---|
| 업무 상태와 결과의 연결 | 접수 상태 전이, 조치 필수 조건, 기록 정합성, 인수인계 초안 | 기록 누락과 다음 근무 전달 누락을 줄일 가능성 | 실제 현장 누락 감소율·처리시간 단축 |
| 기본 업무와 선택형 추론의 분리 | LOCAL 규칙, Provider 계약, 실패 시 LOCAL 복귀, 실행 이력 | 외부 추론 가용성에 기본 기록이 종속되지 않음 | PC 자체 장애, 현장 모델 품질, 고가용성 |
| 사람이 반영하고 Main이 검사하는 책임 경로 | 분석/반영 분리, 계정 현재 상태 검사, 민감 변경 사유·재인증·감사 | 잘못된 추천의 무검토 반영을 줄이고 변경을 추적 | 오반영 감소율, OS 관리자 대상 감사 변조 방지 |

일반 업무도구·CMMS·ITSM 제품과의 제품별 기능 비교는 조사하지 않았다. 비교 기준은 ‘접수·조치·인수인계가 분리된 가상 업무 방식’이다. 비교 대상의 기능 부재를 단정하지 않는다. 상태 머신, 역할 기반 권한, 어댑터, fallback 자체는 일반 설계 패턴이다.

**권장 첫 문장**: “오늘은 메뉴 사용법보다, 업무를 어떤 구조로 연결했고 그 구조를 어디까지 검증했는지 설명드리겠습니다.”

**평가 요청**: 제한된 현장 과업 실증의 필요성과 성공 기준을 검토해 달라고 요청한다. 운영 적합성·보안 승인·연동 완료 판정을 미리 요청하지 않는다.

**발표에서 피할 표현**: ‘AI가 자동 해결’, ‘인터넷 없이 모든 AI 사용’, ‘어떤 모델이든 설정만으로 연결’, ‘실시간 다중 PC 공유’, ‘DELIS 연동 완료’, ‘정확도 78%’, ‘모든 기록 자동 집계’, ‘DB 전체 암호화’, ‘완전한 위변조 방지’, ‘세계 최초’.
